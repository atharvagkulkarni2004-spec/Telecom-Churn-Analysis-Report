# 📞 Telecom Customer Churn Prediction Model

## 📌 Project Overview
A machine learning project designed to predict customer churn in the telecommunications sector. By analyzing customer demographics, usage patterns, and account details, this model successfully identifies at-risk customers, enabling proactive retention strategies.

## 🛠️ Tech Stack
* **Programming Language:** Python
* **Data Manipulation:** Pandas
* **Machine Learning:** Scikit-Learn, Logistic Regression
* **Data Balancing:** SMOTE (Synthetic Minority Over-sampling Technique)

## 📊 Key Features & Performance
* **Imbalanced Data Handling:** Effectively resolved class imbalance in the telecom dataset using **SMOTE**, ensuring the model doesn't become biased toward the majority class.
* **High Recall Rate:** The Logistic Regression model was optimized to prioritize churn detection, achieving an impressive **84% recall rate**, meaning it successfully captures the vast majority of customers who are actually likely to leave.
* **Feature Engineering:** Processed and encoded various categorical and numerical features (e.g., tenure, contract type, monthly charges) to maximize predictive accuracy.
